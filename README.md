# block_tarsus

Course block plugin for the Tarsus ↔ Moodle integration (Lerncoach).

Surfaces student progress + quick access, and teacher dropout-risk alerts via
the Message API (surface now, data later). Depends only on the `local_tarsus`
client interface.

- **Component:** `block_tarsus`
- **Target:** Moodle 5.2 · PHP 8.3
- **Status:** mock-first (Phase 1 = native-data placeholders)

See the project technical specification for full design details.
